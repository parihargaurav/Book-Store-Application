📚 Book Store Application

A full-stack MERN (MongoDB, Express, React, Node.js) project built to manage books with authentication and a responsive UI. The app allows users to perform CRUD operations on books, manage their accounts securely, and interact with a clean frontend styled using TailwindCSS.

✨ Features

🔑 User Authentication

Signup & Login with server-side validation (Joi).

Password hashing with bcrypt for security.

JWT-based authentication for session management.

Middleware for route protection.

📖 Book Management

Create, Read, Update, Delete (CRUD) books.

View books in list or card format.

Book detail pages and modals for better UX.

⚡ Backend (Node.js + Express)

RESTful API with Express Router.

MongoDB & Mongoose for data modeling.

CORS policy setup.

Proper error handling & validation.

💻 Frontend (React + Vite + TailwindCSS)

SPA with React Router DOM.

CRUD operations integrated with backend APIs.

Form validation on client side.

Responsive design with TailwindCSS.

Beautiful alerts and improved user experience.

🛠️ Tech Stack

Frontend: React, Vite, TailwindCSS, React Router DOM

Backend: Node.js, Express.js, Joi, Bcrypt, JSON Web Tokens (JWT), CORS

Database: MongoDB with Mongoose ODM

Other: REST APIs, Middleware, Error Handling

📂 Project Highlights

Backend CRUD with Express & MongoDB.

Secure Authentication with JWT & bcrypt.

Server-side validation (Joi) and client-side validation.

Reusable components (Book Card, Modal).

Interactive and responsive UI.
